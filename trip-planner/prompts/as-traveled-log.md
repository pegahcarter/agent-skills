# As-traveled log

The plan and what happened are different records. Keep both.

Input: the user's notes for a day, while traveling or after.

1. Add a section `## As traveled` at the end of the itinerary if it does not
   exist. One entry per day: where you actually slept, beaches, bars,
   dinners, producers visited, and anything that went wrong.
2. Record only what the user tells you. Do not fill a day from the plan.
3. Where the day differed from the plan, write one line on what changed.
   Leave the date grid as it was planned unless the user asks to change it.
4. In the trackers, add a one-line verdict to the traveler notes for places
   the user visited ("would go back", "skip").
5. Lessons that would change how the next trip is planned (a source that was
   wrong, a closure pattern, a platform problem) go in `sources/catalog.md`
   or the user's own notes, stated as what happened.
